# Telegram Bot

Telegram бот для управления продуктами и раздач.

## Описание

Этот бот предоставляет функциональность для:
- Управления продуктами
- Проведения раздач
- Администрирования пользователей
- Обработки платежей

## Структура проекта

- `main.py` - главный файл бота
- `database.py` - работа с базой данных
- `markups.py` - клавиатуры и разметка
- `utils.py` - вспомогательные функции
- `states.py` - состояния бота
- `handlers/` - обработчики команд
- `assets/` - ресурсы (изображения, файлы)

## Установка

1. Клонируйте репозиторий
2. Установите зависимости: `pip install -r requirements.txt`
3. Настройте токен бота в конфигурации
4. Запустите: `python main.py`

## Требования

- Python 3.8+
- aiogram
- SQLite
